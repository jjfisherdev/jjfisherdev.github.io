Developer website for JJ Fisher LLC (App Store Marketing URL) and the home page of Squeeze: The Estimation Duel.
- `/` and `/fr/`: the Squeeze product page (EN, FR) with schema.org MobileApplication/VideoGame data and an FAQ
  written for how people ask (two players on one phone, offline, couples, VS AI, estimation trivia).
- `/press/`: press kit (fact sheet, descriptions, icon, screenshots).
- `/app-ads.txt`: AdMob verification. Never remove or edit it without updating AdMob.
- `/robots.txt`, `/sitemap.xml`, `/<key>.txt`: crawl permission, sitemap, IndexNow key for Bing.
Support and privacy pages live in the squeeze-support repo (`/squeeze-support/`).
